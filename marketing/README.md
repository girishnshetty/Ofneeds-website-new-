# OfNeeds search marketing drafts

Prepared 3 October 2026; SEO mapping updated 5 October 2026. These files are offline planning assets. Live tracking and ads are disabled at the owner's request. No account has been changed, no advertising budget assigned and no live performance data collected.

## When advertising is authorized later

1. Deploy and verify the updated OfNeeds landing pages first. The production website was still showing the old packages when reviewed.
2. Decide account currency, daily budget and campaign geography. Start with the relevant buyer locations and use presence-based targeting if appropriate; India-wide delivery capability does not imply that every campaign should target all India.
3. Create separate **paused Search campaigns** in Google Ads Editor matching the plan's names. Check Search Network, partner/display settings, language, bidding and geography manually. This plan is not an executable campaign creation import and intentionally assigns no default budget or bidding strategy.
4. Import keyword and responsive-ad CSVs only into the prepared paused campaigns. Use Editor's import preview, map headers and inspect all changes/errors. Status must remain Paused at campaign, ad group, keyword and ad levels. Do not post changes to a live account until explicitly authorized.
5. Add selected sitelinks and callouts manually from the asset sheet. Review the proposed negative phrases to avoid excluding legitimate buyers. Broader matching is omitted from the starting plan.
6. Later, with separate authorization, configure real conversion measurement for accepted enquiries. A WhatsApp click, phone click or opened Tally form is a contact action, not proof of a completed lead. Cross-origin Tally submissions need a supported integration. Avoid sending names, emails, phones or enquiry text to analytics.
7. Check the search-term report and qualified enquiry quality after launch. Keyword Planner research is still needed for volume, CPC and budget estimates; none are inferred from competitor metadata.

The keyword and ad sheets follow standard [Google Ads Editor CSV columns](https://support.google.com/google-ads/editor/answer/57747). The asset limits follow [Google's responsive search ad guidance](https://support.google.com/google-ads/answer/7684791): headline 30 characters, description 90 and display path 15. Account import is not tested because no account is connected and live ads were deferred.

The source competitor's private campaigns, bid strategies, traffic and paid keyword list are not public in its HTML. This package is an OfNeeds campaign proposal derived from relevant public topics, not a claim to reproduce its paid performance.
